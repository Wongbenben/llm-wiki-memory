# 節點 3：組成 HTML → 【關卡 3：版面檢查 loop】

## 3-a 組裝
---
請把 `output/section-1.md` ～ `section-{最後}.md` 組成一頁 `output/index.html`：
- 單一 HTML 檔，CSS 寫在裡面，不用外部框架
- 版面規則（寫死）：
  - `max-width: 800px; margin: auto;` 字體 16px 以上
  - 表格外面包 `<div style="overflow-x:auto">`，手機才不會爆版
  - 圖用 inline SVG 或 HTML/CSS 畫，不要用外部圖片連結
- 頂部：標題＋一句主線；側邊或頂部有章節目錄
- 每個 [S#] 做成連結，連到頁尾「來源」區（列出 S1–S5 標題與網址）
- 結尾彩蛋：「省 token 小技巧」
- 頁尾加一行：「本頁由 LLM Wiki + graph 工作流程產生」
---

## 3-b 版面檢查（loop，最多 2 輪）
---
請檢查 `output/index.html`（第 {第幾} 輪）：
1. 每一節至少有一個表格或一張圖？
2. 用 375px 寬（手機）看，有沒有橫向爆版、文字被切掉？
3. 結尾有沒有來源清單，[S#] 連結都點得到？
全部 OK → 「PASS」；否則 → 「FAIL」，列問題並修改
---

## 停止條件
| 情況 | 處理 |
|---|---|
| PASS | 停，完成 |
| 第 2 輪仍 FAIL | 停，剩下的問題你手動修，記進 log |
