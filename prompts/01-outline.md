# 節點 1：產大綱 → 【關卡 1：大綱審核（人工）】

---

請只讀 `wiki/index.md`（先不要打開其他頁），幫我規劃一頁教學 HTML 的大綱：

- 受眾：同班同學，用過 AI、懂一點 agent
- 主線：「AI 記住的東西，最後都要放進 context window 才有用；放得越多，token 就耗得越多。」
- 必須涵蓋：
  ① 三種記憶（對話內／跨對話／外部檔案）差在哪
  ② 為什麼對話越長，token 越耗、越容易忘
  ③ Claude 實際怎麼記（聊天記憶、CLAUDE.md、自動記憶）
  ⑤ 結尾彩蛋：省 token 小技巧
- 最多 6 節。每節寫：標題、要講的 2–3 個重點、會用到哪些概念頁（[[ ]]）、打算放表格還是圖
- 存成 `output/outline.md`
