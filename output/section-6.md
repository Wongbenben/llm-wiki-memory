## 6. 彩蛋：省 token 小技巧

回到第 3 節的重點：挑選放進 context 的內容，跟視窗有多大一樣重要 [S1]。

### 在 Claude Code 裡
| 技巧 | 怎麼做 | 為什麼有用 |
|---|---|---|
| 換任務就清空 | 換到不相關的工作時跑 /clear [S2] | 舊對話會擠掉你需要的檔案，而且每則訊息都在花 token [S2] |
| 指定重點壓縮 | 開始長任務前跑 /compact focus on ... [S2] | 摘要保留你選的重點，而不是讓自動壓縮去猜 [S2] |
| 把大量閱讀外包 | 把研究交給子代理（subagent）[S2] | 檔案內容留在子代理的視窗，不在你的視窗 [S2] |
| 先看用量 | 跑 /context 看各類別用量和建議 [S2] | 看到實際的 context 用量和最佳化建議 [S2] |
| CLAUDE.md 精簡 | 只跟部分程式有關的指示，搬到 path-scoped rules [S3] | 這些規則只在處理相關檔案時才載入 [S3] |
| 備註寫成 HTML 註解 | 在 CLAUDE.md 用 <!-- 註解 --> 寫給人看的備註 [S3] | 不會花到 context token [S3] |

### 提示快取（prompt caching）：重送的部分打折
第 3 節說過每一輪都會重送之前的對話；prompt caching 的做法是：如果 prompt 開頭那段最近已經快取過，就直接用快取版本，減少處理時間和成本 [S5]。
快取預設可以活 5 分鐘，每次被用到都會免費刷新 [S5]。
多輪對話開啟自動快取時，快取點會隨著對話自動往前移 [S5]。

| 動作 | 價格（相對於一般輸入 token） |
|---|---|
| 寫入快取（5 分鐘） | 1.25 倍 [S5] |
| 寫入快取（1 小時） | 2 倍 [S5] |
| 從快取讀取 | 0.1 倍；Opus 5.5、Sonnet 5.5 是 0.05 倍 [S5] |

想讓快取發揮作用：把固定不變的內容放在 prompt 開頭 [S5]，也不要隨便改工具定義，因為那會讓整個快取失效 [S5]。

但要注意：快取只改變你付多少錢，不會讓這些 token 不算進上下文視窗 [S1]。
