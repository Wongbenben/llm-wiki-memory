## 2. 三種記憶一次看懂

| 記憶類型 | Claude 的例子 | 存在哪、誰寫 | 什麼時候進到視窗 |
|---|---|---|---|
| 對話內記憶 | 上下文視窗本身 | 每一輪的輸入都包含之前所有對話歷史 [S1] | 一直都在，直到滿了被壓縮 [S2] |
| 跨對話記憶 | 聊天記憶、搜尋過去對話 | Claude 在聊天時把記憶存成一個個主題 [S4] | 搜尋舊對話時以工具呼叫的形式出現 [S4] |
| 外部檔案記憶 | CLAUDE.md、自動記憶 | CLAUDE.md 由你寫，自動記憶由 Claude 寫 [S3] | 你還沒打字前就載入 context [S2] |

### 為什麼需要「跨對話」和「外部檔案」？
因為每個 Claude Code session 都是從一個全新的上下文視窗開始 [S3]。
CLAUDE.md 和自動記憶就是用來把知識帶到下一個 session 的 [S3]。
聊天 App 這邊也一樣：S4 形容有了記憶之後，Claude 從無狀態（stateless）的聊天介面，變成會隨時間累積理解的合作者 [S4]。

### 關鍵：最後都要放進視窗
搜尋舊對話的結果是以工具呼叫的形式出現在對話中 [S4]，而工具結果本來就會算進上下文視窗 [S1]。
CLAUDE.md、自動記憶、MCP 工具名稱和 skill 說明，在你打字之前就已經載入 context [S2]。
